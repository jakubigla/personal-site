## Capability
A request for a path that does not exist returns a custom, on-brand 404 page that leads the visitor back to the main page.

## Acceptance
- AC1: Requesting an unknown path returns HTTP status 404.
- AC2: The 404 response body is the custom page, styled like the site.
- AC3: The 404 page has a link back to the main page.
