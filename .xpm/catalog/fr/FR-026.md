## Capability
A visitor downloads a current CV as a PDF, generated from the same content file as the page (print stylesheet or build step), replacing the 2020 PDF.

## Acceptance
- AC1: The page offers a link to download the CV as a PDF.
- AC2: The PDF is generated from the content file during the build; no hand-maintained PDF is committed.
- AC3: Changing a fact in the content file changes both the page and the PDF.
- AC4: The 2020 CV PDF is no longer served.
