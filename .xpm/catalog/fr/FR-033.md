## Capability
When Jakub opens a pull request that edits the content file, the PR check builds the site, attaches screenshots of the built page at 360 px and desktop width, and offers the built site as a downloadable CI artifact, so he sees the change before merging.

## Acceptance
- AC1: A pull request that changes the content file runs a check that builds the site from that file, and a build failure fails the check.
- AC2: The check attaches full-page screenshots of the built page at 360 px width and at a desktop width (1440 px) to the pull request.
- AC3: The built site is downloadable from the check as a CI artifact.
- AC4: The preview is never deployed to a public URL, and the check uses no AWS credentials.
- AC5: Screenshots are taken with reduced motion on, so each section shows its final state and repeated runs give the same result.

## Notes
Implied by Brief Users 4 (Jakub updates content by editing one file and merging a PR). Accepted as Could, not MVP; size S, one ticket. Screenshots and the artifact show only the public page, so NFR-014 and NFR-015 apply to them as they do to the page.
