## Capability
A strip of 4 to 6 numbers or facts (for example years in tech, Champion status, former Resident Solutions Architect, scale figures, certifications count) gives instant proof of the profile.

## Acceptance
- AC1: The proof strip shows between 4 and 6 items, each read from the content file.
- AC2: Each item has a value and a short label that are real HTML text.
- AC3: Changing a proof item in the content file changes the rendered strip without any layout code change.
- AC4: No proof item names a client or combines facts that identify one.
