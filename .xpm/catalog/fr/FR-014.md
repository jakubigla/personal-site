## Capability
The layout keeps a portrait slot that shows a generated, on-brand placeholder graphic (initials or an abstract avatar) at launch and can show a real portrait later by changing one path in the content file.

## Acceptance
- AC1: At launch the portrait slot shows an on-brand placeholder graphic such as initials or an abstract avatar.
- AC2: The placeholder is not a photograph and not a generated face.
- AC3: Changing the single portrait path in the content file replaces the placeholder with the given image, with no layout code change.
- AC4: The portrait image has meaningful alternative text.

## Notes
Decided: placeholder at launch. Not a stock photo and not a generated face. Open decision 2: a real portrait whenever one exists.
