## Capability
Sharing the page link (notably in a LinkedIn post) shows a proper preview card, from a page title, a description, an Open Graph image and Person structured data.

## Acceptance
- AC1: The page has a title and a meta description read from the content file.
- AC2: The page has Open Graph title, description, url and image tags, and the image URL is absolute and returns the image.
- AC3: The page has valid JSON-LD of type Person with name, job title and links to LinkedIn and GitHub.
- AC4: The LinkedIn Post Inspector shows a card with the title, description and image.

## Notes
The site launches with a LinkedIn post, so the link preview matters most.
