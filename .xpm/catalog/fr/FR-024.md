## Capability
Sharing the page link (notably in a LinkedIn post) shows a proper preview card, from a page title, a description, an Open Graph image and Person structured data.

## Acceptance
- AC1: The page has a title and a meta description read from the content file.
- AC2: The page has Open Graph title, description, url and image tags, and the image URL is absolute and returns the image.
- AC3: The page has valid JSON-LD of type Person with name, job title and links to LinkedIn and GitHub.
- AC4: The LinkedIn Post Inspector shows a card with the title, description and image.
- AC5: The Open Graph image is 1200 x 627 px, PNG or JPEG, under 5 MB, and the page declares og:image:width 1200 and og:image:height 627.
- AC6: The build generates the Open Graph image from the content file (name and headline), and no hand-made preview image is committed.
- AC7: Changing the headline in the content file changes the Open Graph image after the next deploy.

## Notes
The site launches with a LinkedIn post, so the link preview matters most.

Elicitation 2026-11-27 Q5: the image is generated at build from the content file to keep one source of truth (NFR-023).

LinkedIn caches previews, so the launch step runs the URL through the LinkedIn Post Inspector before the launch post.

The generated image follows NFR-027: no stock or generated faces, and the portrait only once Jakub supplies a real photo.
