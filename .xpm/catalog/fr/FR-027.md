## Capability
The page shows a light or dark theme to match the visitor's system setting; the light theme draws the same graph in ink on paper rather than glow on navy.

## Acceptance
- AC1: With the system set to dark, the page shows the dark (deep navy) theme.
- AC2: With the system set to light, the page shows the light theme with the graph in ink on paper.
- AC3: Changing the system setting while the page is open switches the theme without a reload.

## Notes
Contrast over the animated background is a WCAG NFR.
