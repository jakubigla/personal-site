## Capability
Champion status is shown as text everywhere it appears; the badge image is shown only when the official credential file issued to Jakub is in assets, and it links to its verification page.

## Acceptance
- AC1: Champion status is rendered as text wherever it appears.
- AC2: When no badge file is configured in the content file, the page ships with no badge image and nothing broken in its place.
- AC3: When the official badge file and its verification URL are configured, the badge image renders and links to the verification page on credentials.databricks.com.
- AC4: The repo contains no Databricks logo or badge other than the official credential file.

## Notes
Do not use a badge copied from another website and do not redraw the Databricks logo or badge. Open decision 1: the exact credential name is checked against the issued credential.
