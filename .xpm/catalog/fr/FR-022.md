## Capability
Jakub updates every fact, label and link on the page by editing one structured content file in the repo and merging a PR; each section can be switched on or off by a flag in that file.

## Acceptance
- AC1: All visible copy, numbers, links and section order come from the single content file.
- AC2: Setting a section's flag to off removes that section from the built page; setting it on shows it.
- AC3: Changing any fact in the content file changes the built page without editing layout code.
- AC4: A content file that does not match its schema fails the build with a message naming the bad field.

## Notes
The file format is chosen in the architecture stage. The same file feeds the CV PDF (FR-026).
