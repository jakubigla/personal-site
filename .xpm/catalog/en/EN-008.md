## Outcome
Generate the page head from the content file so every share and crawl gets a proper card: title, meta description, canonical URL, Open Graph and Twitter card tags, a static Open Graph image of the right size built into the output, and Person structured data in JSON-LD. Nothing in the head is hand-edited, so changing the profile in the content file changes the preview.

## Acceptance
- AC1: The built HTML contains title, meta description, canonical URL, og:title, og:description, og:image, og:url and og:type tags whose values come from the content file.
- AC2: The Open Graph image is served from the site's own origin at 1200 x 627 pixels (FR-024 AC5) and its URL in og:image is absolute.
- AC3: The page contains a JSON-LD Person block that parses as valid schema.org Person data.
- AC4: A link preview check (for example a card validator or a scripted parse of the built head) shows the expected title, description and image.

## Notes
The Open Graph image is rendered at build by Playwright from an /og page sharing the site's templates and tokens (ADR-0007). It uses the placeholder portrait and text only; no badge image until the official credential file exists in assets.
