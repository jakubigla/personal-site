## Outcome
Add a build step (or print stylesheet rendered at build time) that generates the CV PDF from the same content file the page uses, so the downloadable CV can never drift from the page and replaces the 2020 PDF. The PDF is produced as part of the static output and respects the same section flags and anonymized labels.

## Acceptance
- AC1: The build produces a PDF file in the static output without manual steps.
- AC2: Changing a fact in the content file and rebuilding changes the same fact in the generated PDF.
- AC3: A section switched off by its flag is absent from the PDF.
- AC4: The PDF text is selectable (not an image) and contains no real client name.

## Notes
Should item in the brief. The generation tool must not load third-party runtime resources into the published site.
