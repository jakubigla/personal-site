## Constraint
The repository is public from the first commit: it holds no secrets and no private contact details beyond what the page itself shows, in files, history, commit messages, tickets or image files.

## Acceptance
- AC1: A secret scan over the working tree and full git history finds no credentials, tokens or keys.
- AC2: The only contact details in the repository are the ones the page publishes (the public email, LinkedIn and GitHub links).
- AC3: Image files added to the repo carry no embedded metadata that reveals private data (for example GPS or author fields).
- AC4: The check runs in CI on every pull request.
