## Constraint
One scroll timeline drives the motion, but scrolling always stays native: no scroll hijacking, no fixed scroll lengths that trap the user, native scroll speed always; the scroll story is driven by CSS scroll-driven animations where supported and a small IntersectionObserver plus requestAnimationFrame fallback otherwise.

## Acceptance
- AC1: No script calls preventDefault on wheel, touch or key scroll events, and no script sets the scroll position except for an explicit hash navigation.
- AC2: Scrolling speed and momentum match the browser default on desktop and touch devices.
- AC3: The visitor can scroll from the top of the page to the footer without any section holding the scroll position.
- AC4: In browsers without CSS scroll-driven animations, the fallback produces the same final states.

## Notes
Act 1 is skippable by any scroll, key or tap; that skip must not swallow the scroll itself.
