## Constraint
The site launches in English only, but its content and build structure allow a Polish version to be added later without restructuring the layout code.

## Acceptance
- AC1: The page declares lang="en".
- AC2: All translatable text lives in the content file, keyed so that a second language file can be added alongside it.
- AC3: Layout code does not hard-code English strings, including accessible labels and alt text.

## Notes
The Polish version itself is out of scope for the MVP (a Could item).
