## Constraint
The page conforms to WCAG 2.2 level AA, and text colour contrast stays at AA over the animated background in every theme the site offers (the light theme renders the graph as ink on paper rather than glow on navy).

## Acceptance
- AC1: An automated accessibility scan (for example axe) of the built page reports no WCAG 2.2 A or AA violations.
- AC2: Text and interactive element contrast meets AA (4.5:1 body text, 3:1 large text and UI components) against the worst-case frame of the animated background, checked in each theme.
- AC3: Every interactive element (contact links, work cards, theme-dependent controls, CV download) is reachable and operable by keyboard with a visible focus indicator; focus also triggers any highlight that hover triggers.
- AC4: Headings form a logical outline, images carry text alternatives, and decorative canvas or SVG graphics are hidden from assistive technology.
- AC5: Target sizes for links and controls meet WCAG 2.2 target size (minimum) at 360 px width.

## Notes
Light and dark theme itself is a Should feature (brief Need 18); while only one theme ships, AC2 applies to that one.
