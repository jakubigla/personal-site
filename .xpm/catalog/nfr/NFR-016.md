## Constraint
The site sets no cookies and loads no third-party trackers or analytics that set cookies, so no consent banner is needed; the footer privacy note states this truthfully.

## Acceptance
- AC1: Loading and scrolling the full page in a clean browser profile results in zero cookies set for any origin.
- AC2: The page makes no network request to any analytics, advertising or tracking origin.
- AC3: No consent banner is present.
- AC4: The footer privacy note says the site uses no cookies and no tracking, and stays true for every release.
- AC5: Any visit counter added later is cookieless and uses server or CDN logs or a privacy-first method.

## Notes
Browser storage used for UI state (for example "Act 1 already played this session") is not a cookie, but must not identify the visitor.
