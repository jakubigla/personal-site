## Constraint
Every piece of hosting infrastructure (bucket, distribution, certificate, DNS records, response headers, redirects, the deploy role) is defined in Terraform in the repository; nothing is created by hand in the console.

## Acceptance
- AC1: Terraform in the repo defines every AWS resource the site uses, apart from the pre-existing Route 53 zone, which is referenced as data.
- AC2: Terraform format, validate and a static security check run in CI on every pull request.
- AC3: Terraform state is kept remotely with locking, not committed to the repository.

## Notes
An older module (terraform-website-s3-cloudfront-route53, about 2021) may be reused or replaced; the architecture stage decides.
