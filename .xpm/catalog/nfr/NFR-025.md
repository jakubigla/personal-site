## Constraint
All site copy and all code comments use the plain hyphen-minus only; em dashes and en dashes never appear.

## Acceptance
- AC1: The content file and the rendered page contain no U+2014 (em dash) or U+2013 (en dash) characters.
- AC2: Source code comments contain no em or en dashes.
- AC3: A CI check fails a pull request that introduces either character into the content file or source code.
