## Constraint
The two inspiration references contribute techniques only: no assets, copy or layout are copied from them into the site or the repository.

## Acceptance
- AC1: No image, icon, font, illustration or code file from either reference is present in the repository.
- AC2: No copy text from either reference appears on the page.
- AC3: Elements the brief says to leave behind (contact form, phone number, skill percentage bars, emoji avatars, generic AI or ML copy) are absent.

## Notes
One reference is CC BY 4.0; if any asset were ever reused, attribution would be required. The brief rules that out.
