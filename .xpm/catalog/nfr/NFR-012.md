## Constraint
The site is served only over HTTPS through CloudFront with an ACM certificate, HTTP is redirected to HTTPS, the S3 bucket is private and reachable only through CloudFront origin access control, and security headers are set at CloudFront.

## Acceptance
- AC1: The S3 bucket blocks all public access and its policy grants read only to the CloudFront distribution via origin access control.
- AC2: The CloudFront viewer protocol policy redirects HTTP to HTTPS, with a TLS minimum of 1.2.
- AC3: Responses carry at least Strict-Transport-Security, Content-Security-Policy, X-Content-Type-Options nosniff, Referrer-Policy and a frame-ancestors or X-Frame-Options restriction, set by a CloudFront response headers policy.
- AC4: The Content-Security-Policy allows scripts, styles, fonts and images from the site's own origin only (see NFR-017).
- AC5: These properties are asserted by automated tests over the Terraform code (plan or static checks).
