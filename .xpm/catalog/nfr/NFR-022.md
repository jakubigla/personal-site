## Constraint
The xpm autopilot never deploys: the first terraform apply and the DNS cut-over from the current page are attended steps by Jakub; everything up to that point is automated and tested.

## Acceptance
- AC1: No automated workflow runs terraform apply against the production account before Jakub has run the first apply himself.
- AC2: The deploy-on-merge job is inert (skipped or failing safely) until the infrastructure and OIDC role exist.
- AC3: A runbook in the repo describes the first apply and the DNS cut-over steps, including how to roll back to the current page.
