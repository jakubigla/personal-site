## Constraint
All copy and facts live in one structured content file that is the single source of truth for the page and the CV; changing a fact never requires touching layout code.

## Acceptance
- AC1: No user-visible fact, number, label or link is hard-coded in layout, style or script files; all come from the content file.
- AC2: The content file is validated against a schema at build time and a malformed file fails the build with a readable error.
- AC3: Changing any single fact in the content file and rebuilding updates every place it appears (page, link preview, structured data, CV PDF when present).
- AC4: Section on and off flags in the content file control which sections render, with no layout code change.

## Notes
The file format is chosen in the architecture stage. The owner updates content a few times a year by editing this file and merging a PR.
