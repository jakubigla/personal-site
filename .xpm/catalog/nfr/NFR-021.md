## Constraint
The CI pipeline runs on every pull request, including documentation-only ones, and builds, tests and deploys on merge to main.

## Acceptance
- AC1: The CI workflow has no path filters that skip it for documentation-only changes; a docs-only pull request gets a CI run with a status check.
- AC2: Every pull request runs the build and the automated checks (tests, budgets, accessibility, policy checks).
- AC3: A merge to main triggers build, test and deploy.

## Notes
This is an xpm autopilot requirement.
