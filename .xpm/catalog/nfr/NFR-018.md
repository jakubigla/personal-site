## Constraint
The site is static files only: no server-side runtime, no database and no form backend; whichever framework is chosen, the build output is plain static files served from the bucket.

## Acceptance
- AC1: The build produces a directory of static files (HTML, CSS, JS, images, fonts, PDF) that can be served by any static file host.
- AC2: The infrastructure contains no compute (no Lambda, no Lambda@Edge business logic, no containers, no instances) and no database; CloudFront Functions for redirects or headers are the only edge logic allowed.
- AC3: The page contains no form that posts data.
