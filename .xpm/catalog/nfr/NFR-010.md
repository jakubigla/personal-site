## Constraint
3D effects use CSS transforms with perspective, and the graph uses Canvas 2D or SVG; WebGL is allowed only if a prototype proves it fits the performance budget, and then only as a lazy-loaded enhancement after the page is interactive.

## Acceptance
- AC1: The initial page load fetches no WebGL code or shaders.
- AC2: If WebGL is used, it is loaded after the page is interactive, behind a capability check, and the page works fully without it.
- AC3: Any adoption of WebGL is backed by a recorded prototype measurement against NFR-001.
