## Constraint
With JavaScript disabled the page reads top to bottom as a styled CV showing the final state of every act; animation is an enhancement and never the only carrier of any content.

## Acceptance
- AC1: With JavaScript disabled, every section enabled in the content file renders with all its text, numbers, links and images.
- AC2: Numbers that count up with JavaScript show their final values with JavaScript off.
- AC3: The graph, timeline and proof strip show their fully drawn final state with JavaScript off, or a static equivalent.
- AC4: No content is hidden by CSS that only script can reveal (for example reveal classes are applied by script, not present in the static markup).
- AC5: An automated check loads the built page with JavaScript disabled and asserts the presence of each section's key text.

## Notes
Applies to every act of the signature sequence, including Act 1 (which is simply absent without script).
