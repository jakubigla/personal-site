- The deploy role gets no s3:DeleteObject: every deploy overwrites in place and never deletes, which satisfies ADR-0011 (stale non-hashed files simply stay until a manual prune). Bucket name and distribution id reach the deploy job as repository variables SITE_BUCKET and DISTRIBUTION_ID, set with DEPLOY_ROLE_ARN after the attended apply.
- The deploy job runs on a GitHub-hosted runner (ubuntu-latest), never the self-hosted CI_RUNNER, so no third-party build code ever shares a machine with the deploy credential; it uses the AWS CLI that image ships and installs nothing. The GitHub OIDC provider is created by Terraform; if the account already has one it must be imported first (runbook).
