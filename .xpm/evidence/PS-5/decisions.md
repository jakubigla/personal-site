- The deploy role gets no s3:DeleteObject: every deploy overwrites in place and never deletes, which satisfies ADR-0011 (stale non-hashed files simply stay until a manual prune). Bucket name and distribution id reach the deploy job as repository variables SITE_BUCKET and DISTRIBUTION_ID, set with DEPLOY_ROLE_ARN after the attended apply.
- The deploy job runs the AWS CLI already on the runner and installs nothing; on a self-hosted runner without it the job fails after the apply. The GitHub OIDC provider is created by Terraform; if the account already has one it must be imported first (runbook).
